# ورديلڤا — WARDELVA

تطبيق ورد وهدايا بالعربي، مبني بـ Flutter مع دعم كامل لاتجاه اليمين إلى اليسار.

## التشغيل أول مرة

المشروع يحتوي على كود `lib` والأصول فقط، بدون مجلدات المنصات. أنشئها بأمر واحد بعد الاستنساخ:

```bash
git clone https://github.com/<اسم-حسابك>/wardelva.git
cd wardelva
flutter create --platforms=android,ios --org com.wardelva --project-name wardelva .
flutter pub get
flutter run
```

`flutter create` يضيف مجلدي `android` و `ios` ولا يمسح ملفات `lib` الموجودة.

## الفحص قبل أي رفع

```bash
dart format lib test
flutter analyze
flutter test
```

## هيكل المشروع

```
lib/
├── main.dart              نقطة البداية وإعداد اللغة والاتجاه
├── core/
│   ├── tokens.dart        الألوان والزوايا وقواعد العمل
│   ├── theme.dart         ثيم ورديلڤا الموحّد
│   └── formatters.dart    الأرقام العربية وتنسيق المبالغ
├── data/
│   ├── models.dart        المنتج، السلة، الطلب، حالات الطلب
│   └── catalog.dart       بيانات أولية للتطوير
├── state/app_state.dart   حالة التطبيق (سلة، مفضلة، طلبات، نقاط)
├── widgets/               مكونات مشتركة + الشعار الرسمي
└── screens/               الشاشات
```

## الشاشات الجاهزة

البداية، التعريف، تسجيل الدخول، رمز التحقق، الرئيسية، الأقسام، قائمة المنتجات، تفاصيل المنتج مع التخصيص، السلة، التوصيل والدفع، تأكيد الطلب، تتبع الطلب، طلباتي، الولاء، حسابي، المفضلة.

## قواعد العمل

كلها في `lib/core/tokens.dart` داخل `WRules`: أقل قيمة طلب ١٥٠ ريال، رسوم التوصيل ٤٠ ريال، توصيل مجاني فوق ٢٥٩ ريال، كل ريال يساوي نقطة، و٢٠٠ نقطة تعادل ١٠ ريالات.

## الربط بقاعدة بيانات

الشاشات تقرأ من `AppState` فقط، فالربط بـ Supabase يتم بتغيير `AppState` و `Catalog` دون لمس الواجهات:

```bash
flutter pub add supabase_flutter
```

ثم استبدل القراءة من `Catalog` بجلب من الخادم، واحفظ الطلبات في جدول `orders`، واستخدم Realtime لتحديث حالة الطلب لحظياً.

## ما لم يُنفَّذ بعد

تطبيق الفريق، لوحة الإدارة، الدفع الحقيقي، الإشعارات، والبحث. النموذج التفاعلي بالمتصفح يغطي تصميم هذه الأجزاء.
